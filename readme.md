# Redis Mastery Lab

A hands-on journey through **Redis**, from fundamentals to advanced production concepts.

> Learn Redis by building — not just by reading.

## 🚀 What You'll Learn

* Redis fundamentals
* Strings, Hashes, Lists, Sets & Sorted Sets
* TTL & Expiration
* Counters
* OTP systems
* Rate Limiting
* Caching
* Pub/Sub
* Transactions
* WATCH & Optimistic Locking
* Lua Scripts
* Distributed Locks
* Redis Streams
* Consumer Groups
* Geospatial queries
* Bitmaps
* HyperLogLog
* Redis Persistence
* Replication
* Sentinel
* Redis Cluster

## 🏗️ Tech Stack

* **Redis**
* **Node.js**
* **Express.js**
* **ioredis**
* **Docker**
* **Lua**

## 🎯 Goal

Build a strong practical understanding of Redis and learn how it is used in **real-world backend systems and System Design**.

## ⭐ Philosophy

**Don't just learn Redis commands.**

Understand:

> **What problem does Redis solve?**
> **Why Redis is the right tool?**
> **How does it work internally?**
> **Where is it used in System Design?**
